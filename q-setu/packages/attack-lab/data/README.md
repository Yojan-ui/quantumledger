# Training data

`csic2010-sample.jsonl` is a small, cleaned sample of the **HTTP DATASET CSIC 2010**: labelled web
requests to a test e-commerce application, generated by the Spanish National Research Council
(CSIC), Information Security Institute, for testing web attack protection systems. The original
has 36,000 normal training requests and 25,065 anomalous requests (SQL injection, buffer
overflow, information gathering, file disclosure, CRLF injection, XSS, server-side include,
parameter tampering…).

- Source: <https://www.tic.itefi.csic.es/dataset/> (C. Torrano Giménez, A. Pérez Villegas,
  G. Álvarez Marañón, _HTTP data set CSIC 2010_, 2010). Please cite them.
- Copy used to build the sample (the official site was unreachable at build time):
  `normalTrafficTraining.txt` and `anomalousTrafficTest.txt` from
  <https://github.com/msudol/Web-Application-Attack-Datasets> (`OriginalDataSets/csic_2010/`),
  whose counts match the official description.
- The sample: 1,500 normal and 1,500 anomalous requests, taken evenly across each file (every
  24th normal request, every 16th anomalous one). Each row keeps only `method`, `path`, `query`,
  `body` (POST) and `label` (0 normal, 1 attack); headers and cookies are dropped.

The rows contain the dataset's attack strings as plain text. They are training data only: nothing
in the Lab sends them anywhere.

To train on the full dataset instead, put the original `.txt` files in `data/csic2010/` (git-ignored);
`npm run train` uses them when present (trimmed to the newest `MAX_DATASET` requests per class).
