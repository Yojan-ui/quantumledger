---
title: Overview
description: The four ideas behind Q-Setu, in plain language.
---

- **[Hybrid key exchange](/docs/concepts/hybrid-kem):** combine a classical and a post-quantum key exchange,
  so a session is safe if either holds.
- **[Signatures](/docs/concepts/signatures):** ML-DSA proves who sent something and that it wasn't changed,
  including after Q-Day.
- **[Sessions](/docs/concepts/sessions):** pay for post-quantum once per session; every message after it is fast.
- **[Key rotation](/docs/concepts/key-rotation):** keys ratchet and rotate, so one leaked key reveals little.
