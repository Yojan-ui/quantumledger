---
title: Signatures
description: ML-DSA (FIPS 204) for anything that must stay provable after Q-Day.
---

Encryption keeps data secret; signatures keep it **provable**. RSA and ECDSA signatures can be forged
once a quantum computer exists, which matters for anything checked years later: degrees, mandates,
lab reports, audit logs.

| Profile  | Algorithm         | Signature size | Use                                        |
| -------- | ----------------- | -------------- | ------------------------------------------ |
| standard | ML-DSA-65         | 3,309 bytes    | Servers, apps, records                     |
| edge     | ML-DSA-44         | 2,420 bytes    | Devices                                    |
| (option) | SLH-DSA-SHA2-128f | 17,088 bytes   | Long-lived roots; hash-based, conservative |

SLH-DSA's security rests only on hash functions. It's slower and larger, so QuantumLedger offers it as a
policy option rather than the default.
