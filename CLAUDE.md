## Agents
- After changing the web app, run the three-d-guardian and look-keeper agents before committing.
- Use motion-director for 3D scene and motion work, and backend-engineer for APIs, Shield, the ledger and the database.
- Before merging API, Shield or auth changes, run security-reviewer.
- Before any demo, deploy or pitch, run honesty-auditor and judge-rehearsal.
- Keep the current look (dark background, Geist fonts, role colours). Don't redesign it unless the owner asks.
